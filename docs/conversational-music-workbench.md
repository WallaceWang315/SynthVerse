# SynthVerse：对话式音乐灵感工作台

日期：2026-10-08。本文是当前产品定位基线，优先于此前的网页轻型 DAW 与桌面开发方案。网页形态保留，目标从完成完整歌曲调整为持续辅助创作、快速获取灵感与补足乐理知识。

## 核心目标

对话模型贯穿音色设计、旋律动机、和声、节奏、配器与片段编排。用户可以在任意环节开始、跳转、回退或结束，不必遵循完整 DAW 流程。产物可以是一个音色、一句旋律、一组和弦或一段编排；用户决定是否继续发展。

主要价值是让音乐想法变成可听、可比较、可修改的对象。衡量成功的标准是用户是否更快获得值得保留的创意，并理解关键选择，而非完成一首完整歌曲或覆盖 DAW 功能。

## 核心交互闭环

表达想法 → 模型结合当前音乐上下文提出少量候选 → 立即试听 → 比较与选择 → 局部修改 → 保留为创意版本或导出。

对话与音乐对象双向关联。选中音色、音符、和弦或片段后，对话具有明确作用范围；回复中的候选可直接试听、应用和撤销。指令如“保留第二版的节奏，用第一版的声音，结尾更有悬念”要落到明确对象与修改补丁。

## 模型参与方式

| 创作环节 | 模型作用 | 可听见/可编辑的结果 |
| --- | --- | --- |
| 音色设计 | 理解质感、建议合成路线、修改参数 | 可演奏音色、宏参数与候选版本 |
| 动机探索 | 提供短句、节奏变化、呼应与延展 | 1–4 小节 MIDI 乐句 |
| 和声探索 | 为旋律配和弦、为和弦写动机、比较色彩 | 和弦候选、声部排列与试听 |
| 节奏与配器 | 建议低音、鼓和声部间的关系 | 可独立静音、替换的少量片段 |
| 片段编排 | 设计进入顺序、留白、过渡和能量变化 | 短场景或 A/B 段落变体 |
| 乐理辅助 | 解释当前选择并演示替代方案 | 简短说明及修改前后对比 |

模型能介入全过程，不意味着每一步必须调用模型。参数操作和播放保持即时；模板与规则可供无模型时探索。完整对话体验仍是核心验收项，不能只在普通编辑器旁放一个聊天窗口。

## 音乐上下文与权限边界

- 上下文包含当前选区、速度/拍号、调性假设、音符/和弦、音色参数、分析结果、已保留候选及锁定条件。
- 区分参数推断、DSP 分析与实际音频模型分析；模型不能接收音频时，不声称已经听过作品。
- 长对话通过结构化状态和创作摘要维护上下文，不把聊天记录当作工程唯一事实来源。
- 先试听候选，再由用户应用；明确的编辑指令可直接执行并记录撤销。锁定范围不能被修改。
- 候选预览与当前已应用状态分离；生成结果不得覆盖用户等待期间的新编辑，采用版本校验。
- 乐理事实用结构化规则核验，创作建议明确允许其他选择；不把调外音或不协和当成错误。

## 界面定位

主界面是对话与创意对象：对话区、可操作的音色/乐句/和弦卡片、用于验证想法的短片段预览区。钢琴卷帘、声音参数和编排视图按需展开。

保留一个创意收集区，收藏分支、记录差异并提供响度匹配的 A/B 试听。预览可以快速组合几个声部，但不以完整歌曲时间线为默认入口。

## MVP 范围

必须包含：

1. 对话理解当前选区与音乐状态，调用受约束的音乐命令。
2. 可演奏合成器、文字音色修改、参数可视化和少量候选。
3. 短旋律动机、和弦建议与局部变体，支持锁定与撤销。
4. 每条核心建议可试听，乐理解释与实际变化一致。
5. 少量声部组合与短片段编排，用于判断创意是否成立。
6. 创意收藏、版本对比、本地保存和 MIDI/WAV/内部音色格式导出。

暂缓：完整歌曲制作、多轨录音、复杂混音路由、专业母带、全面宿主自动化、完整 DAW 兼容、社交社区及协作编辑。

Vital/Serum 原生预设兼容、本地模型和外部 Agent 仍保留为后续扩展；未验证功能不成为 MVP 门槛。

## 架构影响

保留 TypeScript 网页、音频引擎、音乐调度、乐理库、工程存储与测试方案。将上下文构建器、模型适配、命令校验、候选预览与变更历史提升为核心模块。

统一路径：选区与工程状态 → 上下文构建 → 模型规划 → 音乐工具 → 校验/渲染 → 候选预览 → 应用与撤销。

音频线程不等待网络和模型；生成任务可取消、有预算、失败不破坏当前创意。保存参数、音符、资源及已接受结果，重新打开不要求重新推理。

## 调整后的实施顺序

| 阶段 | 交付重点 | 验收问题 |
| --- | --- | --- |
| C0 声音与命令闭环 | 一个可演奏声音、参数命令、预览/应用/撤销 | 操作是否即时且可恢复？ |
| C1 对话音色伙伴 | 真实模型接入、上下文、文字修改、候选比较 | 能否理解“再柔和一点，但保留起音”？ |
| C2 动机与和声伙伴 | 乐句、和弦、局部锁定及可试听解释 | 能否帮助用户得到一个想保留的音乐想法？ |
| C3 片段编排与创意库 | 少量声部、段落变体、收藏、恢复与导出 | 能否把创意发展一步并交给其他工具继续制作？ |
| C4 高级扩展 | 参考音频、Vital/Serum 兼容、本地模型、外部 Agent | 每项扩展是否改善灵感获取而非仅增加功能？ |

取消以“15 分钟做完并导出八小节作品”为唯一主验收。新的用户测试记录：首次有价值候选耗时、候选保留率、局部修改满意度、锁定遵守情况，以及用户是否能借助试听理解一项乐理选择。具体阈值在原型试用后确定。

## 首个演示场景

用户：“想要有玻璃感但不刺耳的声音。”

系统给出可演奏候选；用户选择一个后：“写一个短动机，有一点忧郁但不要太慢。”

用户选中乐句：“为什么结尾感觉没落下来？给我听两种解决办法。”

系统展示与实际音符对应的解释及候选；用户继续：“保留原节奏，配一组更温暖的和弦，加一点低音看看。”

用户保存或导出这个片段即完成一次成功体验，无需继续制作完整歌曲。

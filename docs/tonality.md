# 调性与调式

在工程标题下选择主音和调式，点击“应用调性”。支持12个主音，以及大调、自然小调、多利亚、弗里几亚、利底亚、混合利底亚、洛克里亚。

- 默认同步转换旋律与和弦：按原音阶级数映射到目标音阶，保留音符 ID、节奏、力度及音色；按转换后的构成音重新识别和弦名称。
- 取消“同步转换旋律与和弦”后仅修改调性参考，适合为已有音乐标注调性。
- 转换遵守和弦锁定；节奏锁定不妨碍只改变音高。支持撤销、重做、本地保存及工程导入导出。旧工程默认 C 大调。
- 主音转换采用最近的半音距离；调外音保留相对下方音阶级数的升高量，不是自动和声重写。音域越界或和弦音重合时拒绝整个转换，提示手动调整。
- 卷帘琴键标签标示调内音和主音，但仍可自由编辑调外音。新增和弦默认为当前调式的主三和弦。
- 本地演示候选与乐理说明读取当前调性；真实 Agent 的工程上下文和提示词也包含调性。参考调性不限制有意使用的借用和弦与经过音。

例如 C 大调切到 D 自然小调，C–E–G–B 转成 D–F–A–C，Cmaj7 变为 Dm7，节奏保持原样。

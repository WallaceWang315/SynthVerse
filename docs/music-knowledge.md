# 内置音乐知识库 v1

这些条目是项目编写的可检索启发式，不是外部教材引文，不提供音乐审美的客观评分。代码中的稳定 ID 与下列锚点对应。

<a id="voicing-space"></a>
## 低音区与开放排列

低音区包含多个构成音时，可以把部分中间声部升高八度，比较密集与开放排列。保持音级并检查 MIDI 33–96 的边界。`low-register-density` 只表示至少三个 C4 以下音，不能证明声音浑浊；需要结合音色与用户试听。

<a id="soft-pad"></a>
## 柔和铺底与起音

尝试降低亮度、减少高次谐波，或放缓起音；一次只调整一个维度。若用户要求保留音色，应转而调整和弦或旋律。频谱重心可以描述声学变化，不能替代“柔和”“梦幻”等主观评价。

<a id="reverb-space"></a>
## 空间感与混响留白

分别小步调整混响量与时长，或通过音符留白避免尾音覆盖新起音。工具传递完整 effects 对象以保留其他效果；有节奏锁定时不能修改音符时长。

<a id="motif-ending"></a>
## 动机结尾与和弦音

先读取结尾时间对应的和弦，再对照构成音与非构成音结尾；非构成音可能提供有意的延伸色彩。使用稳定音符 ID，只修改授权选区。

检索实现为可解释的标签匹配与排序，返回最多三个匹配条目；无匹配返回空结果。只有本轮检索到的 ID 能附在候选引用中。后续可在保持相同接口、来源约束与离线评测的基础上替换为向量或混合检索。

# 当前实施记录

日期：2026-10-08。最新一轮实现可调用音乐工具的创作Agent，并生成可导入、可自动运行的评测场景。

## 本轮完成

- 工程v3稳定音符/和弦ID，v1/v2迁移；局部操作原子校验，锁定和选区按ID定位。
- 9个音乐工具：上下文、符号分析、音色、动机、和弦、注册、渲染、比较、组合。
- Agent最终只引用已注册候选；错误可修正，工具调用和渲染均有预算与去重。
- 浏览器真实离线渲染反馈RMS、峰值、削波比例、能量加权频谱重心、高频能量比例。
- 候选快照、最近12个候选归档、显式参考、目标与偏好；过期快照可作为参考，但旧补丁不能覆盖当前工程。
- 任务关联凭证、渲染jobID校验、重复/过期结果拒绝、45秒限时、取消和手动编辑保护。
- 12个创作场景，含候选比较、多轮续改、四和弦、错误修正和跨候选组合；fixture工程、提示语、自动报告与人工评分表。
- 模拟协议/实际浏览器回归与真实模型agent/direct对照入口；CI已增加创作场景回归。

## 已有音乐工作台能力

分层合成器编辑、3振荡器（最多8声齐奏）、谐波波表、噪声/低八度声源、双滤波、ADSR/调制包络、双LFO、调制连接、效果链；可拖拽/缩放/多选/复制/数值编辑的钢琴卷帘；根音/性质/转位/构成音和时值均可手动编辑的和弦进行。

支持1–16小节、MIDI21–108、256个音符、64个无重叠和弦。播放及MIDI/WAV遵循声部开关与实际时值。本机工程保存、收藏、导入/导出及撤销/重做保留。

## 验证

本机Node22.17.0。53项单元/网关测试、18项Chromium浏览器测试、50个确定性工具约束案例、12个模拟模型加真实音频渲染创作场景通过。生产类型检查及构建通过。执行证据在evals/reports；浏览器截图置于忽略目录.artifacts。

没有配置真实模型账户，未运行真实模型评测或人工音乐质量评分，也未执行远程CI。模拟服务只用于复现工具规划/纠错/续改流程，不是LLM能力证据。

## 当前限制

浏览器音频为独立Web Audio实现，没有运行Vital原生DSP。任意音频生成、波表/采样导入、频谱变形、FM、MPE、Vital/Serum原生预设和插件仍未实现。见vital-integration.md。

当前4/4、参考C大调，任务渲染前至多4小节。模型接收音频指标而非原始音频。无公开服务账户隔离、持久任务队列、向量记忆或外部MCP接口；本轮未增加音频理解模型。未完成Safari/Firefox、移动触控实机和大型工程性能验证。

后续按真实模型agent/direct评测与新手试听结果改进；Vital/WASM/AudioWorklet接入另行验证。Agent协议见music-agent.md，可用场景和评分方法见agent-evaluation.md。

## 琴键按住演奏修复（2026-10-09）

琴键改为按下启动持续音符、松开进入release尾音；支持鼠标、触控、A–K与聚焦琴键的空格/回车，多音同时演奏及按下高亮。拖出琴键仍可正确释放，触控取消、窗口失焦、页面隐藏、离开音色页或打开弹窗会释放持有音符；重复按键不重触发。音量和调制包络均遵循实际按住时长，原有离线片段渲染与钢琴卷帘短音试听保留。

新增5项真实浏览器回归，覆盖按下即启动、长按、释放、和弦、触控取消、失焦、文本输入、短于attack的点按、实际持续音频与空格松开不重触发。

旋律草稿左侧音高琴键也接入持续发声：按下发声、按住保持、松开进入尾音，支持指针捕获、触控取消、聚焦后的空格/回车和失焦释放；仅试听，不修改草稿音符。新增两项浏览器检查，并完成14项琴键与卷帘相关回归及生产构建。
